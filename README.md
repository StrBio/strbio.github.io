# [strbio.github.io](https://strbio.github.io/)
## Structural Bioinformatics @UAM

This is a [Quarto](https://quarto.org/) site containing the materials for the *Structural Bioinformatics* course in the [Master's Degree in Bioinformatics & Computational Biology \@UAM](https://www.uam.es/medicina/en/masterbioinfo). All these materials are open access and shared under [CC BY-NC license](https://creativecommons.org/licenses/by-nc/2.0/ "CC BY-NC license"). 
These materials were originally elaborated for the 2022 course edition and are briefly revised each year. 

If you are student of the Master's, you can find more detailed academic information about the course contents, dates and assessment only can be found at the UAM [Moodle](https://posgrado.uam.es/) site.


Additionally, a short StrBio exercise from a bioinformatics course for undergrad Biochemistry students @UAM is hosted here as an orphan page: <https://strbio.github.io/bims/bims_exercise.html>



> [!NOTE]
> This is primarily an introductory course (3 ECTS), designed to offer a general overview as well as tools and resources necessary for initiating StrBio research projects. Consequently, many fundamental concepts in protein biophysics, scripting tools for StrBio, and deep-learning methods will only be briefly covered.
